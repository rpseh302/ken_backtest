# EMA 20/50 + ATR 전략 구현 설계

Phase 1 데이터 엔진은 수정하지 않는다. 백테스트는 `valid_market_candles`의 검증된
1시간 봉과 `coverage_segments`를 읽고, 각 세그먼트에서만 EMA·ATR 상태를 계산한다.
펀딩비는 별도 `funding_rate.parquet` 파일을 읽으며 OHLCV와 병합하지 않는다.

이벤트 순서는 각 1시간 봉에서 다음과 같다.

1. 이전 봉의 신호에 따른 예약 청산과 진입을 현재 봉 시가에 처리한다. 같은 시각에는
   청산을 먼저 처리하고, 진입 후보는 신호 시점의 EMA 스프레드 내림차순·심볼 오름차순으로
   처리한다.
2. 해당 봉 구간의 실제 펀딩 시각을 처리한다. API 펀딩 시각이 시가보다 수 밀리초 뒤인
   데이터는 해당 시각에 이미 열려 있는 포지션에만 적용된다.
3. 현재 봉의 고가·저가로 ATR 스톱을 검사하고, 갭이면 시가를 기준으로 불리한 슬리피지를
   적용한다.
4. 봉 종가를 사용해 지표·신호를 계산하고, 주문은 다음 봉 시가에만 예약한다.

세그먼트 경계에서 아직 열린 포지션은 가격을 만들지 않고 `DATA_INVALIDATION`으로 명시
종료한다. 따라서 그 거래는 미실현 가격·PnL이 비어 있으며 결과 보고서에서 별도 집계된다.
마지막 유효 봉에서 열린 포지션만 실제 마지막 종가를 기준으로 `END_OF_BACKTEST` 청산한다.
이 정책은 결측 캔들에서 가상 체결을 만드는 것을 방지한다.
